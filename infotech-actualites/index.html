Fonctionnalités

Un socle simple pour agréger l'actualité IT.

Les flux sont importés hors requête web. Les pages publiques lisent ensuite exclusivement la base locale.

01

Import RSS et Atom

Import transactionnel avec normalisation des URL et déduplication des contenus.

02

Catégories hiérarchiques

Classement des articles par catégories et sous-catégories avec navigation dédiée.

03

Recherche intégrée

Recherche dans les titres et résumés des articles publiés.

04

Stockage local

SQLite par défaut, avec compatibilité MariaDB via la configuration d'environnement.

05

Cache applicatif

Mise en cache de l'accueil et de l'arborescence des catégories pour limiter les requêtes répétitives.

06

Docker

Environnement de démarrage reproductible pour faciliter les tests et le déploiement local.

État du projet

Une base fonctionnelle, encore volontairement légère.

Le projet fournit déjà le cœur public. L'administration complète, les rôles avancés, l'éditeur riche et la médiathèque restent à développer.

Distribution propre
